About SimpleSolve AI

HTML5 + CSS3 + Vanilla JS No Frameworks Safe Math Engine LocalStorage DB

🎯 Project Overview

SimpleSolve AI is a beginner-friendly problem-solving chatbot website developed for students and everyday users. It offers instant step-by-step solutions for mathematics, programming explanations, AI/ML concepts, and study assistance.

⚙️ Core Engineering Features

  • Zero eval() Safe Math: Evaluates mathematical expressions using a custom tokenizer and recursive arithmetic evaluator with full BODMAS order.
  • Comprehensive Knowledge Base: Over 40+ curated problem domains across Mathematics, C++, HTML/CSS/JavaScript, Machine Learning, and Study Productivity.
  • ChatGPT-Inspired UI: Dark navy & blue aesthetic, auto-resizing input, typing indicators, rounded bubbles, code formatting with one-click copy.
  • LocalStorage Chat History: Supports multiple persistent chat sessions, switching chats, and deletion.
  • API-Ready Architecture: Clean async design in script.js ready to integrate OpenAI or Google Gemini API.

👨‍💻 Academic Context

Designed as a complete, self-contained college mini-project for B.Tech AIML / CSE students. All code is pure vanilla JavaScript with zero external runtime dependencies.
